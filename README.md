# Duka Quick Sale (Android)

Floating bubble that opens the Duka Sales page in a panel over any app.

## Get the APK
1. Create a GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab, wait for **Build APK** to finish (about 5 minutes; use "Run workflow" if it did not start).
3. Open the finished run, download **duka-bubble-apk**, unzip it and install `app-debug.apk` on your phone (allow "install unknown apps").

## First use
1. Open **Duka Quick Sale**, type your Duka website address, tap **Save address**.
2. Step 1: allow display over other apps. Step 2: allow notifications and camera.
3. Step 3: open the app and log in once.
4. Tap **Start the floating bubble**. Go to TikTok (or any app) and tap the bubble.
